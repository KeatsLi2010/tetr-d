# Web 客户端边界

这里是 React + Vite 浏览器客户端。目前已经提供可用的玩家设置页、键位捕获、Handling 参数、本地导入导出和 Handling Lab；生产构建会由同一 Node 服务静态托管。

## 本地优先输入

所有玩家配置只保存在浏览器 `localStorage`，不会随连接、认证、入房或对局上传。物理按键由本地 Handling 引擎按玩家自己的 DAS、ARR、DCD 和 SDF 展开成具体操作：

- 单格横移或移至墙边；
- 下移指定格数或 Sonic Drop；
- 旋转、Hold、硬降等离散操作。

操作先应用于本地预测器，再立即进入发送队列。队列不等待 `match.inputAck` 才发送下一批，因此一个 RTT 内可以有多个输入批次同时在途。ACK 和 snapshot 只用于确认、纠偏与重放。

服务器仍负责验证操作是否合法，并权威决定碰撞、锁定、消行、攻击、垃圾、KO 和最终结果。客户端不能提交坐标、消行数、攻击量或胜负。

完整比赛棋盘、幽灵块、攻击动画和对手小窗应使用独立 Canvas/WebGL renderer，不让 React 逐格渲染高频状态。下一阶段还需把本地预测器接入完整方块生命周期，并实现 snapshot 回滚重放、对手插值与音频。
